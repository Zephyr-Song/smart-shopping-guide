# 视频网页设计解析 & BFC 原型映射

## 一、原视频里是什么网页

视频展示的是一个**中国传统文化 × 高端定制游**的品牌落地页/导览产品（画面里出现的品牌名近似 "GUAVCIN / PREMSAN LAKE"）。

从画面判断，它大概率是：

1. **先由 Figma / After Effects / Blender 做高保真动效设计**，再导出成视频用于提案或宣传；
2. 也可能是一个真实 Web App 的录屏，只是某些文字区域被 AI 生成内容填充（你能看到部分文案是乱码/希腊字，这是典型的 "greeking" 占位）。

## 二、视觉语言拆解

| 原视频元素 | 设计意图 | 技术实现方式 |
|---|---|---|
| 深黑背景 + 顶部暖金光束 | "夜间宫殿/园林" 的氛围 | `radial-gradient` 叠加 + 深色底色 |
| 金色衬线标题 | 高端、东方、仪式感 | `Noto Serif SC` / 任何衬线字体 + `linear-gradient` 文字裁剪 |
| 漂浮的小灯笼/粒子 | 古风、灵动、引导视线 | CSS 动画（`@keyframes rise`）或 JS 粒子库 |
| 中式线描建筑/花窗 | 文化符号、边框装饰 | 纯 SVG `<path>` 描边，放固定角落 |
| 四角回纹装饰 | 传统纹样、卡片贵气感 | CSS `border` 切角 + 4 个绝对定位的 corner 元素 |
| 深色卡片 +  hover 浮起 | 内容模块、可探索感 | CSS Grid + `transform: translateY` + `box-shadow` |
| 中心辐射导航 | 4 个核心功能入口 | 绝对定位圆环 + 4 个 orbit node |
| 人物/服装网格 | 旅拍、汉服体验推荐 | CSS Grid + 图片卡片 |

## 三、用到的前端技术栈（最小可用版）

- **HTML5 + CSS3**：全部布局、渐变、动画、SVG 线描
- **Google Fonts**：衬线字体（中文推荐 `Noto Serif SC`，英文可用 `Playfair Display`）
- **原生 JS**：生成粒子、处理点击与简单对话
- **可选增强**：
  - `GSAP`：做更复杂的滚动动画、入场动画
  - `Three.js`：如果要做真正的 3D 灯笼/宫殿背景
  - `Lottie`：把 AE 做的复杂动效导出 JSON 播放

## 四、原视频 vs BFC 原型映射

原视频的场景是「传统文化导览」，BFC 是「海派摩登商业体」，但设计语言可以直接迁移：

| 原视频 | BFC 原型 |
|---|---|
"CULTURAL GUIDE" | "外滩风尚指南" |
深黑 + 金色 | BFC 夜场 + 外滩灯光金色 |
中式亭台楼阁 SVG | 上海外滩建筑天际线 SVG |
Yuyuan Garden 卡片 | 博悦汇影城 / TZ HOUSE / 复星艺术中心 |
汉服旅拍网格 | 拍照机位 / 市集 / 餐饮推荐 |
中心辐射菜单 | 精致餐饮 / 打卡机位 / 亲子 / 宠物友好 |

## 五、给你的开发建议

### 如果要做真实产品（而非宣传视频）

1. **先做 PRD**：目标用户是谁、来 BFC 的核心场景有哪几个、每个场景用户会问什么问题。AI 可以帮你写，但决策得由 PM（你）下。
2. **再定信息架构**：聊天是不是唯一入口？是否还需要卡片导航、地图、活动日历？
3. **视觉风格二选一**：
   - 黑金国风（视频这种）→ 适合文化/艺术/夜游定位
   - 极简白 + BFC 品牌色 → 适合高端购物/商务场景
4. **工程实现**：当前原型是纯静态 HTML，要接到 BFC 导购助手上，需要把 `agentEngine.ts` 里的 `runAgent` 或者 Worker API 接到聊天输入框。

### 如果只是想"复刻视频里的网页效果"

- 最快路径：用我这份 `prototype-bfc-cultural.html` 当起点，替换图片、文案、SVG 线描。
- 进阶路径：在 Figma 里把关键帧画成组件 → 导出 SVG/图片 → 我用 React + Tailwind 实现成真实页面。
- 炫酷路径：AE 做动画 → Bodymovin 导出 Lottie → 网页里直接播放。
